通过 **GitHub 学生开发者礼包 (GitHub Student Developer Pack)**，我们可以直接在知名域名服务商 **Name.com** 免费申请长达 **1 年** 的顶级域名（如 `.live`、`.tech`、`.me` 等），同时还附赠**免费高级隐私保护（Advanced Security / WHOIS Privacy）**与免费 SSL 证书。

本文将结合完整实操步骤，带你从零顺利拿下你的专属域名。

1. **GitHub 账号**：已通过学生认证，拥有 [GitHub Student Developer Pack](https://education.github.com/pack) 资格。
2. **Name.com 账号**：如果没有，可在操作流程中直接注册。

## ✦ 详细操作步骤

### 第一步：访问专属合作页面并绑定 GitHub 授权
1. 打开上述链接，进入 Name.com 的 GitHub 学生专属活动页。
2. 页面中会提示通过 GitHub 学生礼包验证资格。点击页面上的 **Log in with GitHub** 按钮。
3. 登录你的 GitHub 账号并点击授权。验证通过后，页面会提示你已成功获得学生免费域名权益资格。

### 第二步：挑选与搜索心仪的域名
1. 在搜索框中输入你想要注册的个性化域名前缀（例如：`yourname`、`myblog` 等）。
2. 在搜索结果列表中，注意选择带有优惠或属于学生礼包覆盖后缀的域名（常见免费后缀包括 `.live`、`.tech`、`.me` 等）。
3. 找到心仪且显示支持权益的域名后，点击 **加入购物车 (Add to Cart)**。

### 第三步：检查购物车与免费附加福利
1. 点击右上角购物车进入结算流程。
2. 勾选 **免费高级安全保护 (Advanced Security / WHOIS 隐私保护)**：Name.com 会贴心为学生提供免费的 WHOIS 信息隐私保护，隐藏真实邮箱和个人信息，防止被垃圾邮件打扰。
3. 检查右侧应付金额：学生礼包会自动抵扣域名的首年注册费，结算总金额应为 **$0.00**。

### 第四步：完成注册与信息核对
1. 如果尚未登录 Name.com，根据提示完成账号登录或新建账号。
2. 填写真实的联系人信息与域名所有者信息（注意：有隐私保护的情况下，公网无法查到个人信息）。
3. 确认订单金额为 **0 元** 后提交订单，即可完成注册！

## ✦ 常见问题与避坑提示

:::tip
**Q: 点击链接显示 `error=promo_used` 或提示优惠已使用？**  
每个 GitHub 学生包通常仅支持在 Name.com 领取一次免费域名权益。如果你之前已经领取过该权益，则无法再次免费申请。
:::

:::note
**Q: 域名领取成功后该怎么用？**  
1. 登录 Name.com 控制台进入 **My Domains（我的域名）**。  
2. 找到刚申请的域名，进入 **DNS Records** 设置。  
3. 将域名解析（A 记录 / CNAME 记录）指向你的服务器 IP、Vercel、Cloudflare Pages 或 GitHub Pages，即可绑定到你的独立博客小站！
:::
