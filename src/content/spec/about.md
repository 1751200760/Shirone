# 关于 Blueberry

欢迎来到 **Blueberry** 的个人小站！这里记录我的学习历程、生活碎片、技术探索以及所热爱的一切。

本站基于开源博客主题 **Shirone** 构建，采用 **Material 3 Expressive (M3E)** 现代化二次元设计语言打造。

::github{repo="1751200760/Shirone"}

## ✦ 关于博主

- **博主**：Blueberry
- **格言**：向着光前行，不负每一次相遇与热爱。
- **兴趣**：技术开发、开源分享、动漫与数字生活

## ✦ 站点特性

- **动态主题配色**：基于 Material 3 HCT 算法驱动，支持浅色/深色模式及多款色彩风格无缝切换。
- **流畅无缝浏览**：采用 Swup 驱动的持久化外壳（Persistent Shell），页面切换平滑，音乐播放不中断。
- **现代化技术栈**：基于 Astro 构建，结合 Svelte 岛屿架构，兼顾极致性能与灵动交互。
- **纯粹写作体验**：全面支持丰富 Markdown / MDX 语法扩展、代码高亮、离线全文检索等。
